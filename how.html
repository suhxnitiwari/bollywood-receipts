How it's built

A gossip site with a data pipeline: public records for the facts, a receipt for every rumour, and a map computed once so your browser never has to.

The pipeline

From a database to a dinner party

  1. Pull the recordsA Python script queries Wikidata's public SPARQL endpoint for every Hindi-language film since 1930 (about 6,900) with its cast, director, producers and composer, then fetches spouses, parents, children, siblings, birth years and Commons photos for everyone involved. All of it is CC0.
  2. Decide who's a guestAnyone with 5 or more acting credits, or 3 or more as director, producer or composer, gets a seat, plus everyone the hand-checked layer already mentions. Names are matched to Wikidata ids once, so "Kareena Kapoor" and "Kareena Kapoor Khan" stay one person.
  3. Layer the gossip on topDating, feuds, friendships, engagements and rumours aren't in any database. They're written by hand, one fact-checked line each, and they always win: if the hand-checked data already relates two people, Wikidata's version is ignored.
  4. Run the site's own code to build the graphThe build loads the real page scripts in a headless DOM (jsdom), so the offline tools see exactly the graph the browser will build. Nothing is maintained twice.
  5. Lay out the room once, offlineA Node script uses graphology to cluster and seat everyone, then writes plain coordinates. The browser only draws.
  6. Cut the portraitsPhotos are fetched politely (three at a time, backing off on rate limits), cropped square with sharp and saved as small WebP files, so the map never pulls multi-megabyte originals.
  7. Ship static filesNo server, no framework: HTML, CSS and vanilla JavaScript on GitHub Pages, with the map drawn on a canvas.
The receipts

Every rishta carries a stamp

A gossip site is only worth reading if you can tell what's proven. So every hand-written link is stamped with how sure we are, and the map's "Receipts only" switch hides everything that isn't proven.

Receipt757 links

On the record: a statement, an interview, a filing or a credit.

Alleged70 links

Reported by credible outlets, never confirmed by the people involved.

Rumour17 links

Persistent gossip with nothing behind it, shown so you know it's only gossip.

Faux4 links

Debunked or manufactured, like a romance a film's PR team planted.

Every pasted lead is checked before it goes in, and plenty don't survive: quotes that can't be found are cut, not softened. The features each end with their sources, and every link was tested for dead pages.

  • Khandaans start at their own tables. Each of the 20 family trees gets a seat on a golden-angle spiral, so the Kapoors and the Khans begin apart.
  • ForceAtlas2 settles the room. 1,600 iterations in LinLog mode, then a no-overlap pass so faces don't sit on each other.
  • Louvain finds the circles. Community detection on the weighted graph names the friend groups and eras that aren't a family.
  • Size is gravity. Gossip counts twice, a filmography counts on a curve (films0.7), so a long career makes a bigger guest without drowning out the drama.
  • It's reproducible. The layout uses a seeded random number generator, so the same data always gives the same room.
The connector

Pulling the thread

"Name any two guests" runs Dijkstra's shortest path over the whole graph, in your browser. Each step costs 100 plus a small weight for the kind of link, so the answer is always the fewest hops, and among equally short routes it prefers a marriage over a cameo. Filters reuse the same search: "Family" walks only blood and marriage, and "Receipts only" refuses any link that isn't proven.

The stack

What it's made of

In the browser

HTML, CSS and vanilla JavaScript. Canvas 2D for the map, the intro and the skyline. No framework, no build step for the pages, hosted free on GitHub Pages.

In the build

Python and SPARQL against Wikidata. Node with graphology, ForceAtlas2, noverlap and Louvain for the layout, jsdom to run the site's own scripts headless, and sharp for the portraits.

Film, family and photo data from Wikidata and Wikimedia Commons (CC0 and the photos' own licences). Gossip, verdicts and writing by Bollywood Receipts.
